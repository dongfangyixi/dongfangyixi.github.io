## Markdown works out of the box

You can use **bold**, *italics*, `inline code`, lists, and code blocks:

```js
function greet(name) {
  return `Hello, ${name}!`;
}
```

To add a new post, drop a `.md` file in `src/content/blog/`. The filename
becomes the URL (e.g. `hello-world.md` → `/blog/hello-world`).
